# Praveen Sinwar · Portfolio

My personal developer portfolio: a single HTML page with an interactive 3D mechanical keyboard built in Three.js (keys press when you type, and typing commands like `projects` navigates the page), plus about, experience, projects with real code snippets, and contact.

**Live:** https://cryoviper.github.io/portfolio/

- Plain HTML, CSS and JavaScript; Three.js loaded from a CDN for the hero
- Responsive from 360px phones up, keyboard accessible, respects reduced motion
- Pauses the 3D scene when it is off screen, and renders only when something changes

Built by [Praveen Sinwar](https://github.com/cryoviper).
