# Praveen Sinwar · Portfolio

My personal developer portfolio: a single, dependency-free HTML page with a Three.js 3D monogram, projects with live demos and code links, skills, experience and contact.

**Live:** https://cryoviper.github.io/portfolio/

- Plain HTML, CSS and JavaScript; Three.js loaded from a CDN for the hero
- Responsive from 360px phones up, keyboard accessible, respects reduced motion
- Pauses the 3D scene when it's off screen to save battery

Built by [Praveen Sinwar](https://github.com/cryoviper).
