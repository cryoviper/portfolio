Featured project

Algo Lab, a DSA visualizer

Watch 6 sorting and 5 pathfinding algorithms run step by step. Each sort is a generator that yields its steps, so the animation code never touches the algorithm. Draw walls and weights, generate mazes, and compare how A* and Dijkstra explore.

  • JavaScript
  • Generators
  • Binary heap
  • node:test · 42 tests
Live demo Source
js/sorting.js
export function* insertion(a) {
  for (let i = 1; i < a.length; i++) {
    let j = i;
    while (j > 0) {
      yield { t: "cmp", i: j - 1, j };
      if (a[j - 1] <= a[j]) break;
      [a[j - 1], a[j]] = [a[j], a[j - 1]];
      yield { t: "swap", i: j - 1, j };
      j--;
    }
  }
}

// BM25 score of one passage for the query
for (const t of terms) {
  const f = doc.tf.get(t);
  if (!f) continue;
  score += idf(t) * (f * (k1 + 1)) /
    (f + k1 * (1 - b + b * doc.len / avgLen));
